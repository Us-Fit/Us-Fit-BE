카카오 로그인 테스트 폼

플랫폼 > 웹 사이트 도메인에 이 페이지 도메인(예: http://localhost:8080)을 등록해야 팝업 로그인이 동작합니다.
참고: JavaScript 키는 access_token이 아닙니다. 키로 SDK를 초기화한 뒤 팝업 로그인 시에 access_token이 발급됩니다.
프론트 주도 플로우에서 받은 access_token으로 서버가 카카오 userinfo를 조회합니다.
서버가 code → token 교환 후 userinfo 조회를 수행합니다. redirect_uri가 백엔드 설정과 일치해야 합니다.
